XT Signal Bot - نسخه اندروید

این برنامه فقط سیگنال می‌دهد و هیچ سفارش یا برداشت/انتقالی در XT انجام نمی‌دهد.
داده‌های عمومی K-Line فیوچرز XT را مستقیم از API عمومی دریافت می‌کند.

استراتژی:
EMA 5/10/20/100/200 + MACD + RSI + Volume + ADX

سیگنال ورود:
BUY ENTRY یا SELL ENTRY وقتی امتیاز جهت مربوطه حداقل 7 از 9 باشد و تازه از آستانه عبور کرده باشد.

خروج:
EXIT LONG / EXIT SHORT بر اساس افت امتیاز یا کراس EMA5/EMA10.

تایم‌فریم‌ها: 1m, 5m, 15m, 30m, 1h, 4h, 1d

نکته: برای دسترسی مستقیم به API در ایران ممکن است VPN لازم باشد. از VPN با IP ثابت فقط در صورت نیاز استفاده کنید.

ساخت APK:
- Android Studio: پروژه را باز کنید و Build > Build APK(s) را بزنید.
- یا در GitHub یک repository بسازید، فایل‌های این پروژه را upload کنید و Workflow با نام Build XT Signal Bot APK را اجرا کنید. فایل APK از بخش Artifacts قابل دریافت است.

هشدار: این برنامه ابزار تحلیل است، نه تضمین سود. قبل از استفاده واقعی، سیگنال‌ها را روی حساب آزمایشی/دمو و با سرمایه بسیار کم بررسی کنید.
